# winsnap

**轻量级 Windows 窗口管理工具** —— 用 Alt + 鼠标/键盘快速移动、调整大小、贴边吸附。

## 功能概览

| 功能 | 描述 |
|------|------|
| 拖拽移动 | `Alt + 鼠标左键` 拖拽移动任意窗口 |
| 调整大小 | `Alt + 鼠标右键` 拖拽调整窗口大小 |
| 贴边吸附 | 拖拽时自动贴屏幕边缘 / 其它窗口边缘 |
| 快速定位 | `Alt + 小键盘 1-9` 九宫格定位 |
| 快速贴边 | `Alt + 方向键` 贴屏幕四边 |
| 等比缩放 | `Alt + 滚轮` 等比例缩放窗口 |
| 居中窗口 | 托盘菜单「全部居中」|
| 动画移动 | 开关切换，平滑 ease-out 动画 |
| 开机自启 | 托盘菜单一键开关 |
| 单例控制 | 多次启动自动接管旧实例 |

## 快捷键

### 鼠标操作
| 操作 | 快捷键 |
|------|--------|

| 调整大小 | `Alt + 鼠标右键` 拖拽（从哪个方向开始就调整哪边）|
| 等比例缩放 | `Alt + 滚轮`（上滚放大，下滚缩小）|

### 键盘操作
| 操作 | 快捷键 |
|------|--------|
| 快速定位 | `Alt + 小键盘 1-9`（九宫格布局）|
| 贴左/右/上/下 | `Alt + ←/→/↑/↓` |
| 暂停/恢复监听 | `` ` ``（反引号）|

### 托盘菜单
- **全部居中**：将所有可见窗口居中到各自所在显示器
- **开机自启**：双保险（启动文件夹 + 注册表 Run 键）
- **开启动画**：控制 `Alt+数字/方向键` 移动是否使用平滑动画
- **屏幕吸附**：`Alt+左键` 拖拽时贴屏幕边缘（默认开启）
- **窗口吸附**：`Alt+左键` 拖拽时贴其它窗口边缘（默认关闭）
- **禁用监听**：暂停所有快捷键和鼠标监听
- **退出**：关闭程序

## 实现细节

### 整体架构

```
main.rs
├── main()              入口，DPI 设置，定时器精度，单例控制
├── run_interactive()    启动 rdev 监听线程 + 托盘线程 + 主轮询循环
└── poll_mouse()        ~120Hz 鼠标状态轮询 + 拖拽/吸附逻辑

tray.rs                 系统托盘（图标、菜单、鼠标钩子、看门狗）
keyboard.rs             rdev 键盘/滚轮事件分发
anim.rs                 窗口移动动画线程
snap.rs                 窗口吸附（屏幕 + 窗口边缘吸附）
state.rs                全局原子状态与修饰键查询
config.rs               Win32 API 封装（窗口操作、坐标、DWM）
single.rs               单例控制（互斥体 + 进程接管）
autostart.rs           开机自启（快捷方式 + 注册表）
log.rs                 带颜色的日志辅助
```

### 鼠标拖拽实现

采用**双通道检测**策略，保证 Alt+鼠标 操作可靠触发：

1. **低层鼠标钩子**（`WH_MOUSE_LL`，在 `tray.rs` 中由托盘线程安装）：
   - 回调中检测 `Alt+左键/右键` 组合，检测到后：
     - 立即 `return LRESULT(1)` 吞掉消息，阻断窗口内部处理
     - 原子变量 `HOOK_DRAG_REQUEST` 置位（1=移动，2=调整大小）
   - 原子变量 `MOUSE_LEFT_HOOK` / `MOUSE_RIGHT_HOOK` 记录按键状态

2. **主线程轮询**（`poll_mouse()`，~120Hz）：
   - 首先检查 `HOOK_DRAG_REQUEST`，零延迟响应
   - 备用：若钩子未安装或 miss，直接用 `GetAsyncKeyState` 检测
   - 检测到 `Alt+左键` → 记录窗口句柄和起始位置，`ReleaseCapture()` 释放鼠标
   - 拖拽中实时更新窗口位置（mode=1 移动，mode=2 调整大小）
   - 左键释放时**去抖**（<24ms 的钩子状态抖动不结束拖拽）

### 窗口吸附实现

#### 屏幕吸附
- 基于 **DWM 可视矩形**（`DwmGetWindowAttribute(EXTENDED_FRAME_BOUNDS)`），而非窗口帧矩形
- 拖拽结束时检测可视边缘与屏幕边缘距离，≤7px 自动吸附

#### 窗口吸附（`snap.rs`）

采用**矩形区间裁剪**算法实现被遮挡边缘的可见性判断：

1. **候选窗口收集**：拖拽开始时枚举所有可见顶层窗口，排除最小化/隐藏/桌面层
2. **可视矩形记录**：每个候选记录帧矩形与 DWM 可视矩形的四边差值
3. **逐帧可见性刷新**：
   - 用所有更高 Z 序窗口的可视矩形，对候选的四条边做**一维区间裁剪**
   - 被遮挡部分的投影区间扣除后，剩余可见总长 ≥ 边长 1/3 则该边"可见"
4. **吸附锚点生成**：可见边缘产生锚点（相邻对齐 + 同向对齐）
5. **方向约束**：已贴近（≤7px）或正在靠近才触发吸附；拖离 >30px 才脱开

### DWM 坐标体系

关键坑点：Windows 在**系统缩放**（如 125%）下，`GetWindowRect` 返回**虚拟化坐标**（缩放前），而 DWM 返回**物理像素**。

**解决方案**：
- 声明 `Per-Monitor Aware v2`（`SetProcessDpiAwarenessContext(DPI_AWARENESS_CONTEXT_PER_MONITOR_AWARE_V2)`）
- 在创建任何窗口前调用，保证所有 API 坐标一致
- 所有位置计算基于 DWM 可视矩形，尺寸/偏移用差值换算

### 平滑动画

- **触发条件**：动画开关开启时，`Alt+数字/方向键/贴边` 操作触发
- **算法**：`ease-out cubic`（先快后慢），时长 200-400ms 随距离自适应
- **线程模型**：后台线程执行动画，不阻塞主线程 ~120Hz 鼠标轮询
- **中止条件**：新动画请求 / 用户开始拖拽 / 窗口销毁 → 立即退出
- **定时器精度**：`timeBeginPeriod(1)` 将系统定时器分辨率从 15.6ms 提升到 1ms，避免动画帧间隔抖动

### 托盘图标

- **图标来源**：嵌入程序的 `.ico` 资源（`build.rs` + `winres`）
- **图标状态**：监听启用时彩色，暂停时灰度（Rec.601 亮度公式灰度化并缓存）
- **消息监听**：
  - 左键单击：切换控制台显隐
  - 右键单击：弹出菜单
- **看门狗**：每 5 秒检查托盘图标是否丢失（Explorer 重启导致），自动重建
- **TaskbarCreated**：监听 `RegisterWindowMessageW("TaskbarCreated")`，Explorer 重启后自动重建图标

### 单例控制

1. 首次运行：创建命名互斥体，记录 PID 到临时文件
2. 再次运行：检测互斥体已存在 → 定位旧实例
3. 旧实例托盘健康：发 `WM_TRAY_RESTORE` 请求重建，等待 2 秒确认
4. 托盘失效或无响应：终止旧进程，继承互斥体

### 开机自启

双保险机制：
1. **启动文件夹快捷方式**（`Shell:::{679f85cb-0220-4080-b29b-7171e7bc11af}`）
2. **注册表 Run 键**（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`）

## 适用环境

### 支持的 Windows 版本
| 版本 | 支持状态 | 备注 |
|------|----------|------|
| Windows 10 (1809+) | ✅ 支持 | |
| Windows 11 | ✅ 支持 | |

### DPI 缩放支持
- ✅ **Per-Monitor Aware v2** — 支持每个显示器独立缩放比例
- ✅ **裸机 + 虚拟机**：在 VMware、Hyper-V 等虚拟机中正常运行

### 多显示器支持
- ✅ 支持多显示器环境
- ✅ 支持显示器尺寸/分辨率不同的情况
- `Alt+数字定位` 和 `Alt+方向键贴边` 作用于前台窗口所在显示器

### 触摸设备
- ⚠️ 触摸操作（触摸屏/触控板手势）不触发鼠标钩子
- ⚠️ 触摸拖拽窗口需要配合鼠标模拟器使用

### 游戏 / 全屏应用
- ⚠️ 游戏全屏时 Windows 会限制窗口操作，部分游戏可能无法移动/调整
- ⚠️ 某些全屏独占模式（DirectX Fullscreen）的游戏完全无法介入

### 网络会议室 / 远程桌面
- ⚠️ `rdev` 在 RDP 会话中可能无法正常工作
- ⚠️ `GetAsyncKeyState` 在 RDP 中行为与本地不同

### UWP 应用
- ✅ 基本支持（Word、Edge 等）
- ⚠️ 部分 UWP 应用窗口边界获取可能不准确（已在代码中做 `DwmGetWindowAttribute` 补偿）

## 注意事项

1. **Alt 键为全局触发键**：winsnap 使用 Alt 作为所有操作的修饰键，确保不会与目标应用的快捷键冲突
2. **无配置文件**：所有配置（吸附开关、动画开关）仅存内存，关闭即丢失，重启恢复默认
3. **管理员权限**：无需管理员权限即可使用，但部分被 UAC 保护的窗口（如任务管理器）可能无法操作
4. **杀软误报**：Rust 静态编译的原生程序可能被部分杀软标记，介意者可自行编译
